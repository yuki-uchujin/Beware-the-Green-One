# Beware the <span style="color:#148110;">Green One</span>

**Beware the <span style="color:#148110;">Green One</span>. Something is getting <span style="color:#A32626;">stronger</span>. Every time.**

## What is happening?

Something is wrong with the <span style="color:#148110;">Creepers</span>.

Every time a <span style="color:#148110;">Creeper</span> explodes, its next explosion becomes more powerful.

The explosion count persists in the world, so there is no escaping the consequences.

## Features

- Creeper explosions become progressively stronger
- HUD displays the current explosion count and multiplier
- Explosion power can reach extreme levels
- Configurable HUD position and visibility
- First explosion starts at normal strength — but it won't stay that way

## Can you survive?

<span style="color:#A32626;">****Probably not.****</span>

## Compatibility

- Minecraft 1.20.1
- Forge
